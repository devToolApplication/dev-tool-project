## 1. Problem Statement & User Goal
Đội ngũ kỹ sư và QA phát triển AI Agent trên hệ sinh thái Codex SDK / Claude Agent hiện phải dùng Postman và cURL để gọi các endpoint của `ai-agent-mcrs`, đối soát log JSON thô và kiểm thử prompt. Việc này gây mất thời gian (3-5 phút/lần debug), dễ nhầm lẫn giữa các session và không có khả năng quan sát streaming trực quan.

**Mục tiêu cốt lõi:** Cung cấp màn hình quản lý lịch sử chat và kiểm thử tương tác (Workbench) tại `/codex-sdk/threads` trong portal `dev-tool-web` (Angular 21) để tìm kiếm, tra cứu chi tiết hội thoại và gửi prompt test SSE streaming trong thời gian thực dưới 3 giây.

## 2. Information Architecture & UX Structure

Hệ thống áp dụng kiến trúc **Table + Drawer Workbench**:

```
+---------------------------------------------------------------------------------+
| dev-tool-web: /codex-sdk/threads                                                |
+---------------------------------------------------------------------------------+
| [app-page-shell] Tiêu đề: "Lịch sử Chat Codex SDK"                              |
|                                                                                 |
| [app-action-toolbar]                                                            |
|  - [ Làm mới ]  - [ Mở Workbench test ] (Mở Drawer trống để gửi turn đầu)       |
|  - Toolbar Cursor Navigation: [ Trang trước ] [ Trang sau ]                     |
|                                                                                 |
| [app-filter-panel]                                                              |
|  - Tìm kiếm từ khóa: [ searchTerm ]                                             |
|  - Trạng thái lưu trữ: [ Tất cả | Hoạt động | Đã lưu trữ ]                      |
|                                                                                 |
| [app-table] TableConfig<CodexThreadItem>                                        |
|  +---------------------------------------------------------------------------+  |
|  | Thread ID | Preview Prompt | Số lượt chat | Ngày tạo | Hành động          |  |
|  +---------------------------------------------------------------------------+  |
|  | thread-01 | Phân tích PR.. | 4 lượt       | 10:30    | [ Xem chi tiết ]   |  |
|  +---------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------+
```

### Drawer chi tiết & Test Prompt (`CodexChatDrawerComponent`):
- **Bọc trong `app-drawer`:** `side="right"`, kích thước responsive: 650px trên desktop (>= 768px), bung toàn màn hình (100% full-width) trên mobile (< 768px).
- **Khung Timeline đàm thoại (Collapsible Inline Inspector):**
  - Bong bóng chat phân biệt rõ: User bên phải, Assistant bên trái trên nền mờ `var(--app-surface-variant)`.
  - **Tool Calls:** Nằm gọn gàng bên trong turn của Assistant dưới dạng Accordion. Mặc định thu gọn hiển thị tên tool, runtime latency. Nhấp mở sẽ hiển thị payload JSON / stdout bằng `app-json-viewer`.
  - **Turn Metrics:** Hiển thị Model, Token count, Latency tinh gọn ở footer của từng tin nhắn.
  - Tích hợp nút sao chép `app-copyable-text`.
- **Khung Test Prompt cố định đáy (Compact Quick-Bar):**
  - Chiều cao tinh gọn (~110px).
  - Selector Model (`claude-sonnet-5`, `claude-opus-5`, `gpt-5.2`) và Reasoning Effort (`low`, `medium`, `high`) ngay đầu input.
  - Nút "⚙ Nâng cao" mở popover cấu hình System Instruction & Sandbox mode (`read-only` vs `workspace-write`).
  - Textarea tự động co giãn, hỗ trợ phím tắt `Enter` xuống dòng, `Ctrl+Enter` gửi prompt.
  - Nút Gửi (disabled khi streaming) và nút Dừng Stream đỏ nổi bật khi `isStreaming = true`.

## 3. Interaction States & Error Recovery

| Thành phần UI | Loading State | Empty State | Error State | Success State | Partial / Streaming State |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Bảng danh sách Thread** | Skeleton rows shimmer | Biểu tượng thư mục trống + nút "Tạo phiên test mới" | Banner báo lỗi kèm nút "Thử lại" | Hiển thị danh sách bảng kèm phân trang cursor | Cập nhật cursor điều hướng trang |
| **Drawer Lịch sử Chat** | Skeleton bubbles | Canvas trống hướng dẫn "Nhập prompt bên dưới để bắt đầu phiên mới" | Thông báo lỗi tải lịch sử thread | Hiển thị trọn vẹn danh sách turns đàm thoại | Giữ nguyên các turn đã nạp |
| **Khung gửi Test Prompt** | Nút gửi chuyển trạng thái loading spinner | Khung nhập trống, nút gửi disabled | Hiển thị toast lỗi BE + banner inline kèm nút Retry | Reset ô nhập prompt, thêm turn mới vào timeline | Nút Dừng Stream hiển thị, chữ sinh ra theo token thời gian thực |

**Quy tắc phục hồi lỗi Partial Stream (D3 Cleared):**
Khi stream bị đứt quãng giữa chừng, giao diện giữ nguyên 100% lượng token đã sinh ra trước đó, hiển thị banner cảnh báo lỗi inline kèm nút "Thử lại" (Retry) để gửi lại prompt mà không làm mất dấu vết debug.

## 4. Technical Constraints & Rules Compliance

1. **Quy chuẩn Frontend (`docs/note/fe-note.md`):**
   - 100% sử dụng Shared Components: `app-page-shell`, `app-action-toolbar`, `app-filter-panel`, `app-table`, `app-drawer`, `app-button`, `app-copyable-text`, `app-json-viewer`.
   - Tuyệt đối không import trực tiếp từ `primeng/*`.
   - Không sử dụng `::ng-deep` hoặc `:host-context`.
   - Toàn bộ chuỗi hiển thị qua i18n Transloco (`codex_sdk.*`).
2. **Quy chuẩn Kiến trúc & Streaming:**
   - Frontend `dev-tool-web` chỉ gọi qua gateway `ai-agent-mcrs` (không gọi trực tiếp execute service).
   - Sử dụng native Web API `fetch()` + `ReadableStream` (`response.body.getReader()`), không dùng thư viện ngoài `@microsoft/fetch-event-source`.
   - Quản lý ngắt kết nối an toàn qua `AbortController` gắn với lifecycle của Drawer và chuyển thread.
3. **Quy chuẩn Thiết kế Anti-Slop (/design-taste-frontend):**
   - Dials: `VARIANCE: 4`, `MOTION_INTENSITY: 4`, `VISUAL_DENSITY: 8`.
   - Bảng màu trung tính điềm tĩnh, không dùng gradient tím lố lăng, loại bỏ hoàn toàn ký tự gạch ngang dài (em-dash).
