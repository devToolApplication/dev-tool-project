Lựa chọn Thiết kế Hiển thị Tool Calls & Turn Metrics

Cách biểu diễn các lượt gọi công cụ (Tool Calls), payload JSON và thông số đo lường hiệu năng trên Timeline

Phương án 1: Inline Accordion Card (Linear Style) Khuyên dùng
Assistant Turn #3
Tôi đã kiểm tra repository và tìm thấy các file sau:
▶ tool: bash (git_status) 320ms • 1 call
$ git status --short
M services/ai-agent-mcrs
?? dev-tool-web
claude-sonnet-5 1,420 tokens • 1.6s

Đặc điểm: Giữ nguyên mạch đọc đàm thoại. Các lệnh tool thu gọn thành thanh bấm, khi cần xem log chi tiết chỉ cần click mở rộng ngay tại chỗ.

Phương án 2: Sequential Step Cards (BPMN/Timeline Flow)
Step 1 • User
Check git status giùm tôi
Step 2 • Tool Call: bash 320ms
command: "git status --short"
Step 3 • Assistant Result
Repository có 2 thay đổi...

Đặc điểm: Trải từng bước tuần tự theo thời gian thực như một workflow engine. Phù hợp cho QA debug sâu từng step nhưng chiếm nhiều diện tích cuộn.
